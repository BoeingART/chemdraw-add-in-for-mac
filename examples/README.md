# Try a drawing that has already made the trip

**Start with the [current vector drawing examples](vector/README.md).** They contain genuine vector bonds and labels, a recognizable ChemOffice identity, and portable native source.

The [earlier portable examples](portable/README.md) preserve the first four-direction copy/paste run. Those older files have raster artwork inside their carrier and are retained as historical evidence.

The earlier examples below preserve the original close-test evidence. They predate the portable format; their copy behavior is not the current workflow.

Start **Start ChemOffice.command**, then open one of these documents and double-click its figure. The editable source is stored inside the document. Edit in ChemDraw and use **⌘W** to return.

| Example | Word | PowerPoint |
| --- | --- | --- |
| The last typed `Z` survived immediate closing | [Open Word example](word/Last%20edit%20preserved.docx) | [Open PowerPoint example](powerpoint/Last%20edit%20preserved.pptx) |
| A new chemical bond survived immediate closing | [Open Word example](word/Last%20bond%20preserved.docx) | [Open PowerPoint example](powerpoint/Last%20bond%20preserved.pptx) |

Use one example at a time. The two versions for each application share a drawing identity so their history can be compared. Keep the whole document when copying an example; the PowerPoint source travels in a separate hidden box on the same slide.

The `.cdxml` and `.json` files beside each example are evidence from its acceptance run. They let you compare the final drawing and verification results without changing the saved example. See [the test report](../docs/live-test-results.md) for scope and limitations.
