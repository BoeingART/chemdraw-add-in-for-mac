ChemDraw Add-in for Mac Installation Complete

The app will open Add-in Setup automatically to check Word file access, PowerPoint file access, Accessibility, and the paste helper.

Allow access to the Word and PowerPoint apps you use when prompted. The app will verify directory access and start the helper automatically. Click “Done” when all four checks pass.

When upgrading from an older version, confirm Accessibility and Automation access when prompted.

If file access is denied, click “Authorize File Access Again” or “Repair Add-in” in the main window. Allow access when prompted; setup will continue automatically.

Use “Check for Updates” to download and install new versions in the app. The app will reopen automatically after installation.

Copy a structure in ChemDraw and paste it into Word or PowerPoint. Double-click to edit, save to update the Office image, and close the ChemDraw document to return to your original document.
