ChemDraw Add-in for Mac Installation Complete

The app will open Add-in Setup automatically to check Word file access, PowerPoint file access, Accessibility, and the paste helper.

Allow access to the Word, PowerPoint and Excel apps you use when prompted. The app will verify directory access and start the helper automatically. Click “Done” when all five checks pass.

When upgrading from an older version, confirm Accessibility and Automation access when prompted.

If file access is denied, click “Authorize File Access Again” or “Repair Add-in” in the main window. Allow access when prompted; setup will continue automatically.

In Word, PowerPoint or Excel, test double-click editing, Command-S synchronization, and closing with write-back. Check that no extra windows or spinning pointer indicators appear.

Saving a structure keeps the ChemDraw editing window open. Save your Office document when you choose.
