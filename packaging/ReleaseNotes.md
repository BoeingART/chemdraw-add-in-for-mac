# ChemDraw Add-in for Mac 2.0.1-beta

## 中文

- 修复 PowerPoint 中相同的 ChemDraw OLE 对象在复制粘贴后无法打开的问题。每个副本可独立编辑，保存时只更新当前副本。

下载 DMG，将应用拖到 Applications 并替换旧版。首次使用时，按“设置加载项”的提示完成授权。

## English

- Fix an error opening identical ChemDraw OLE copies pasted in PowerPoint. Edit each copy independently and save changes to the selected copy.

Download the DMG and drag the app into Applications to replace the previous version. On first use, follow the prompts in Set Up Add-in.
