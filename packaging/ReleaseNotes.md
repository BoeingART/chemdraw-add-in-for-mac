## ChemDraw Add-in for Mac 2.0.0 — Development

### 中文

- 新增 Windows ChemDraw OLE 文件实验：提取 PowerPoint 内的结构，在 Mac ChemDraw 中编辑，再导出保留 OLE 对象和矢量预览的 PPT 副本。
- 支持用 Mac CDX 源文件生成新的 OLE 演示文稿；导出使用新文件名，保留原文档和源文件。
- 实时 OLE 回写、插入及 Word／Excel 的 OLE 接入继续开发。现有可编辑图片的粘贴和保存同步继续使用。

### English

- Add Windows ChemDraw OLE file experiments: extract PowerPoint source, edit it in Mac ChemDraw, and export a copy retaining OLE objects and vector previews.
- Create new OLE presentations from Mac CDX files. Export to new filenames and retain the original documents and source files.
- Live OLE write-back, insertion, and Word/Excel OLE integration are in development. Existing editable picture paste and save synchronization continue to operate.
