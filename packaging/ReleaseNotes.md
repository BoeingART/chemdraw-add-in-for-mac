# ChemDraw Add-in for Mac 2.0.0-beta

## 中文

- 新增 Word、PowerPoint 和 Excel 的原生 ChemDraw OLE 粘贴与保存同步，支持打开 Windows ChemDraw 嵌入结构。
- 在 ChemDraw 按 ⌘S 或选择“保存”即可更新原 Office 结构并保持编辑窗口打开；支持尚未保存的新文档及文档切换。
- 支持编辑 PowerPoint 组合中的 ChemDraw 对象，保留组合内其他图形、裁剪和文字；减少打开与保存耗时。
- 修复 Word 保存时临时窗口闪现、重复对象及修订模式回写问题；操作失败时保留编辑草稿并显示重试方法。
- 修复鼠标按下与释放配对，改善双击打开、菜单粘贴及关闭编辑窗口的响应；完善跨页预览和绘图设置保留。

下载 DMG，将应用拖到 Applications。首次打开后，在“设置加载项”窗口按提示完成 Office 文件访问及辅助功能授权，助手就绪后即可使用。适用于 Apple 芯片和 Intel Mac。

验证范围：Word 和 PowerPoint 已有应用内操作验证；Excel 已完成文件格式和事务检查，原生 OLE 应用内验收待完成。

## English

- Add native ChemDraw OLE paste and save synchronization for Word, PowerPoint and Excel, including opening embedded Windows ChemDraw drawings.
- Update the original Office drawing with Command-S or menu Save while keeping the ChemDraw editor open. Support unsaved documents and switching between documents.
- Edit ChemDraw objects inside PowerPoint groups while retaining companion artwork, cropping and text. Reduce opening and save synchronization time.
- Fix temporary Word windows, duplicate objects and save-back with revision tracking. Retain editing drafts and show retry steps after failures.
- Correct mouse press/release pairing for double-click opening, menu paste and editor closing. Improve multi-page previews and preservation of drawing settings.

Download the DMG and drag the app into Applications. Open the app and complete Office file-access and Accessibility permissions in Set Up Add-in. Start using it when the helper is ready. Supports Apple silicon and Intel Macs.

Validation coverage: Word and PowerPoint have application-level checks. Excel native OLE has file-format and transaction coverage; application-level acceptance remains pending.
