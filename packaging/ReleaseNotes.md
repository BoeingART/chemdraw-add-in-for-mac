## ChemDraw Add-in for Mac 1.5.3

### 中文

- 修复更新下载完成后，旧版应用无法退出、安装更新一直停住的问题。
- 准备更新、停止助手和重新打开期间持续显示进度；失败时显示原因，保留下载文件并支持重试。
- 保留已有授权、Office文档和编辑草稿，当前结构编辑结束后自动继续更新。
- 从1.5.1或1.5.2更新时若已卡住，请在活动监视器中结束旧版应用，再通过本页DMG安装一次1.5.3；后续版本使用修复后的内置更新。

### English

- Fix updates stalling after download when the old application could not finish quitting.
- Show progress during preparation, helper shutdown and restart. Display failures, retain the download and allow retry.
- Retain existing permissions, Office documents and editing drafts. Active drawing edits finish before updating.
- If an update from 1.5.1 or 1.5.2 is already stalled, end the old app in Activity Monitor and install 1.5.3 once using this release’s DMG. Later releases use the repaired in-app updater.
