# Prototype architecture

This project implements custom managed pictures, not native OLE objects or an Office add-in. The installed ChemDraw remains the editor.

1. On an explicit Office ⌘V, the Swift annotated-session event tap recognizes native ChemDraw CDX or a ChemOffice graphic on the clipboard. It snapshots source and preview from one pasteboard generation; unrelated pastes pass through. ⌘C remains the application's ordinary Copy operation.
2. Each paste receives a fresh identity. ChemDraw exports the captured native source as `Scalable Vector Graphics (SVG)`. Its visible paths and text are preserved; no raster fallback is inserted if export fails. Python adds a white vector canvas and stores checksum-protected source in a PNG iTXt entry inside an **invisible transparent 1×1 image**. Office strips ordinary SVG metadata but preserves this payload in the tested versions. One graphic therefore carries its source without a companion shape or external registry. Word alternative text and PowerPoint shape names contain `ChemOffice Drawing:<UUID>`; legacy identities remain readable.
3. A managed-picture double-click resolves the original document and source. Both hosts read the actual referenced SVG from the saved OOXML package for new short identities. Source is materialized under `work/sessions/<drawing-id>/` as native `.cdx` or `.cdxml` and opened in ChemDraw. Native activation must confirm the exact focused ChemDraw window before success. Only one editing session is supported.
4. The event tap holds the managed window's ⌘W or recognized red-button event. While committing, it suppresses further key-down and mouse-down events directed to that managed ChemDraw window.
5. ChemDraw receives a short settling interval, exits its live text editor, saves with bounded clean-state checks, and exports native SVG. A reference PNG is rendered locally from that SVG using resvg-py for verification only. A different active document, remaining dirty state, invalid source, or failed render aborts the transaction.
6. The original Office figure's source must still match its opening version (or the same new version from a partial retry). The adapter replaces the picture with the vector carrier, preserves its width, updates height to the new aspect ratio, updates source, and saves the Office document.
7. Python reads the saved OOXML package, follows the actual SVG or legacy-picture relationship, compares exact source bytes, and compares the normalized preview. Only then may the clean ChemDraw document close. Native accessibility activation selects the exact Office window before the host adapter selects the original figure, including when another document of the same application became active.

Failures retain the session and editable draft. They do not provide cross-application rollback or a guarantee against process crashes. A monitor restart reloads a retained session; the native helper watches its parent process so an abandoned event tap does not continue intercepting input.

A repeated double-click on the same identity reopens or reveals the retained draft without overwriting it with older embedded source. If a different figure is requested while the previous window is absent, the stale draft and session record are archived under `work/recovery` before the new edit begins. If the previous drawing is still open, it is revealed and the second edit is refused. Activation failure leaves the session resumable.

`src/carrier.py` constructs and reads portable graphics, `src/automation.py` owns application object-model calls, `office/*/adapter.applescript` owns host-specific behavior, and `src/verification.py` verifies the saved document. Stable `work/office-preview-*.svg` files allow a one-time Office grant to known previews without accessing another application's protected container.

Native CDX uses the `CFM2` envelope; legacy XML retains `CFM1`. Both include identity, checksum, and compressed source. CDX signature and size are checked before insertion; ChemDraw parses its chemical contents on opening. No conversion through SMILES or a substitute drawing engine is used. Old hidden-box PowerPoint fixtures remain readable; a successful update writes the portable carrier and removes their managed source box.

No keystroke text or general clipboard history is logged. Explicitly pasted chemistry is retained locally in `work/pastes` for recovery. Normal logs contain identity, document path, gestures, errors, source hashes, and focus evidence. Optional `CFM_DIAGNOSTICS=1` additionally records pointer targets and close-button hit-test coordinates; it is off by default.
