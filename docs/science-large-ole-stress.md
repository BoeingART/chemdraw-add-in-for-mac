# Science 文档大结构回写验收

2026-11-03，本地构建 2.0.0 Build 35。

## 修复

Science-V5.3.docx 包含五个 ChemDraw OLE，原生 CDX 数据分别为 379588、1425552、1301229、68483、323814 字节。文档开启了修订。原范围替换被记录为删除与插入，导致对象重复，随后定位和回写失败；已在副本中复现相同错误。

Word 回写改为从隐藏暂存文档复制原生 OLE，使用原生粘贴覆盖完整 EMBED 范围，避开长文档连续更新时会停滞的跨文档 FormattedText 赋值。替换与恢复期间临时暂停修订，成功及失败后恢复原开关。代码未接受或拒绝用户已有修订。源数据验证结束后释放暂存文档的剪贴板所有权，再恢复用户原剪贴板。

操作错误改用独立警告弹窗，显示操作名称、具体原因和继续操作方式。同一错误状态的轮询只显示一次；新的操作失败会再次报告。授权和安装检查继续使用设置窗口。助手启动和退出错误也通过弹窗报告。

## 实际应用验证

使用原文件的独立副本，每个副本分配独立文档标识。原文稿不写入、不保存。每个对象在 ChemDraw 中修改标签设置并原生保存三次，再运行正式回写事务。

| 对象 | 原始 CDX 字节 | 验证通过的保存次数 |
| --- | ---: | ---: |
| 1 | 379588 | 3 |
| 2 | 1425552 | 3 |
| 3 | 1301229 | 3 |
| 4 | 68483 | 3 |
| 5 | 323814 | 3 |

累计十五次保存均通过。每次读回全部五个 OLE 的 CDX，核对对应快照及其余对象；核对正文、对象数量、修订数量、修订开关、编辑窗口和未保存状态。另在对象 1、3、4、5 上分别注入暂存后及替换后读回失败，共八次，恢复检查均通过。

最终样本的保存与全部对象读回检查耗时 4.61–6.50 秒。此范围包含测试额外读取其他四个对象的耗时，不用于承诺用户操作延迟。ChemDraw 重新保存旧 CDX 后，文件体积会缩小。

部分样本触发 ChemDraw 22 的未知对象兼容性提示，测试由人工确认后继续。测试程序等待 Word 加载文档及读回传输对象后才关闭预检文档。相关证据位于 `build/science-stress/accepted-matrix.log`、`accepted-remaining.log`、`accepted-summary.json` 及对应 acceptance 目录。

探索测试中，Word 在取消积压的旧格式化赋值提示时意外退出。用户已确认恢复。原文件保持原样，当前编辑草稿和会话记录另存于 Downloads/ChemDraw-Recovery-20261103；这次退出发生在最终原生范围粘贴验收之前。旧助手的临时暂停已解除。
