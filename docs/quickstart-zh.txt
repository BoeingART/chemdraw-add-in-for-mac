ChemOffice for Mac v1.0.6 · 安装与使用

安装包：ChemOffice-for-Mac-1.0.6-universal.pkg（Apple Silicon 与 Intel 通用版）
要求：macOS 12 或更新；已安装并激活 ChemDraw 及 Word／PowerPoint。

安装与升级

1. 完成当前 ChemDraw 编辑，保存正在处理的文档并退出 ChemOffice。
2. 打开安装包，按 macOS 安装器步骤更新“应用程序”中的 ChemOffice。
   macOS 提示拦截时，在“系统设置 → 隐私与安全性”中选择“仍要打开”。
3. 安装后自动打开“完成安装”窗口。也可从“应用程序”打开 ChemOffice。
4. 点击“打开文件访问设置”，在“文件与文件夹 → ChemOffice”下启用 Microsoft Word 和 Microsoft PowerPoint。
   程序会自动配置加载项并验证绘图缓存可读写。
5. 点击“打开辅助功能设置”，在“辅助功能”中启用 ChemOffice。
   macOS 27 的对应入口为“设备控制和数据访问”。
6. 授权后窗口会自动更新，粘贴助手自动启动。全部通过后点击“开始使用”。
   首次编辑时，允许 macOS 提示的 ChemDraw、Word、PowerPoint 自动化控制。

直接粘贴与编辑

1. 新建或打开 Word 文档／PowerPoint 演示文稿。
2. 在 ChemDraw 中选中结构并按 ⌘C，到 Office 中按 ⌘V，或右键选择“粘贴”。
   也可在 ChemOffice 面板点击 Paste editable drawing。
   新建、尚未保存的文档也可直接粘贴。
3. 双击结构，在 ChemDraw 中继续编辑。
4. 用 ⌘W 关闭当前 ChemDraw 绘图窗口，将修改带回原来的 Office 文档。
5. 按自己的工作节奏手动保存 Office 文档。
6. 使用结束后选择 Quit ChemOffice。下次打开 ChemOffice 会检查授权并自动启动助手。

在 Office 中打开面板

在“完成安装”窗口点击“启用 Office 面板”，完成本机连接设置，保存手头工作并重新打开 Office。
Office 2021 / 16.78：插入 → 我的加载项下拉菜单 → 开发人员加载项 → ChemOffice for Mac。
部分布局位于“插入 → 加载项 → 我的加载项”。
新版 Office：开始 → 加载项 → 开发人员加载项 → ChemOffice for Mac。
激活后，使用 ChemOffice → Open ChemOffice 打开右侧面板。
如面板提示本地连接证书问题，在 ChemOffice 菜单选择 Trust Local Connection 并完成 macOS 认证，随后重新打开 Office。

常用菜单

完成安装：查看权限状态并继续自动配置。
Start Helper：重新检查并启动编辑助手。
Stop Helper：暂停助手；点击 Start Helper 恢复。
Check Installation：查看加载项、Office 版本、预览目录和连接状态。
Install Office Add-ins：打开“完成安装”窗口，自动安装或修复加载项。
Trust Local Connection：完成本机面板连接设置。
Open Local Data：打开绘图源数据、恢复草稿和日志。
Installation Guide：打开本指南。

授权需要处理时

文件与文件夹中分别确认 Microsoft Word 和 Microsoft PowerPoint 已打开。
辅助功能授权后如仍显示监听失败，移除旧 ChemOffice 项，重新添加“应用程序”中的 ChemOffice 并启用，再点“重新检查”。
保留“完成安装”窗口即可自动继续，无需重新安装。

本机数据保存在 ~/Library/Application Support/ChemOffice/work。
Office 预览位于各自沙盒的 Library/Caches/ChemOffice 中。升级应用会继续使用已有的绘图数据和恢复草稿。

粘贴状态

面板显示结构处理进度及具体失败原因。出现错误时按提示处理后重新复制粘贴。
编辑中的结构可粘贴为新的独立副本；原编辑仍回写原文档。已关闭的编辑草稿会保留在 recovery 中。
