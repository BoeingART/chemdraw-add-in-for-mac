ChemDraw Add-in for Mac v1.3.3 · 安装与使用

安装包：ChemDraw-Add-in-for-Mac-1.3.3-universal.pkg（Apple Silicon与Intel通用版）
要求：macOS 12或更新；已安装并激活ChemDraw及Word／PowerPoint。

安装与升级

1. 完成当前编辑并退出应用，然后打开安装包。
   macOS提示拦截时，在“系统设置 → 隐私与安全性”中选择“仍要打开”。
2. 安装后自动打开“设置加载项”，显示四项检查。
3. 在系统提示中允许访问所用的Microsoft Word和Microsoft PowerPoint，
   或点击“打开文件访问设置”，在“文件与文件夹 → ChemDraw Add-in for Mac”中启用。
4. 点击“打开辅助功能设置”，启用ChemDraw Add-in for Mac。
   macOS 27的对应入口为“设备控制和数据访问”。
5. 授权后会自动配置加载项、验证目录读写并启动粘贴助手。
   四项检查通过后点击“完成”。首次编辑时允许ChemDraw和Office自动化控制。

主界面

设置加载项：查看Word文件访问、PowerPoint文件访问、辅助功能和粘贴助手四项检查。
检查更新：在应用内下载新版本，显示下载进度并支持取消。
下载完成后选择“安装并重新打开”；当前正在编辑时，用⌘W结束编辑后再点“安装更新”。
修复加载项：恢复被拒绝的Office文件访问，重新配置所用加载项，并按提示完成本地面板的连接授权。
打开和回写绘图时，指针旁会显示跟随移动的转圈提示，完成或失败后自动消失。
主界面不再显示状态段落，退出入口位于菜单栏中。
设置为开机启动项：勾选后在登录Mac时自动启动；系统要求确认时，按提示允许。

菜单栏

应用默认显示在右上角，使用透明背景的白色轮廓图标。菜单顶部显示当前版本。
菜单仅提供检查更新、打开界面、隐藏图标和退出应用。
关闭窗口后助手继续运行。隐藏图标后，从“应用程序”重新打开即可恢复图标和主界面。

直接粘贴与编辑

1. 新建或打开Word文档／PowerPoint演示文稿。
2. 在ChemDraw中选中结构并按⌘C，到Office按⌘V或右键选择“粘贴”。
   也可在面板点击Paste editable drawing。新建、尚未保存的文档也可直接粘贴。
3. 双击结构，在ChemDraw中继续编辑。
4. 在ChemDraw按⌘S或选择“保存”，原Office图片会自动更新，编辑窗口保持打开。用⌘W结束编辑并返回原文档。
5. 按需要手动保存Office文档。切换窗口、保存或另存为后，修改仍返回原文档。
6. 关闭原Office文档时，对应ChemDraw编辑窗口会自动关闭，最新本地草稿保留。

在Office中打开面板

在主界面点击“修复加载项”，按提示完成本地连接授权，然后重新打开Office。
Office 2021 / 16.78：插入 → 我的加载项下拉菜单 → 开发人员加载项 → ChemDraw Add-in for Mac。
新版Office：开始 → 加载项 → 开发人员加载项 → ChemDraw Add-in for Mac。
激活后，从ChemDraw Add-in for Mac功能区打开右侧面板。

授权与恢复

安装和升级重新请求Word／PowerPoint文件访问，按系统提示允许。从旧版升级时，按系统提示确认辅助功能和自动化授权。
文件访问被拒绝时，点击“重新授权文件访问”或主界面的“修复加载项”，在新提示中允许访问。
程序会自动检查目录读写并继续配置、启动助手。
辅助功能授权后如仍显示监听失败，移除旧项，重新添加“应用程序”中的
ChemDraw Add-in for Mac并启用，再点“重新检查”。

本机数据保存在~/Library/Application Support/ChemOffice/work。
升级和更名继续使用已有的绘图、证书和恢复草稿。
Office预览位于各自沙盒的Library/Caches/ChemOffice中。

面板和主界面显示处理进度及具体失败原因。按提示处理后重新复制粘贴。
编辑中的结构可粘贴为独立副本；原编辑仍回写原文档。已关闭的草稿保留在recovery中。
